# Checklist avaliador

- [ ] Requisitos e cenários observáveis, sem alteração indevida da baseline.
- [ ] Fonte atual, achado, tarefa e prova ligados.
- [ ] Implementação conectada ao fluxo externo real.
- [ ] Contratos, autorização, custos e limites explícitos.
- [ ] Custódia, concorrência, erro e retomada demonstrados.
- [ ] Migração histórica/dados preservados.
- [ ] Um ecossistema Compose conforme AGENTS.
- [ ] Gate integrado sem skips obrigatórios.
- [ ] Relatórios/matrizes coerentes com hashes/digests testados.
- [ ] OpenSpec strict passou.
- [ ] Pendência comercial/normativa não foi aprovada por inferência.
- [ ] Baseline v4/R2/R3 vinculada foi requalificada antes de encerrar.
